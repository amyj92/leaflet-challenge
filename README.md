# leaflet-challenge

In Part 1 of this challenge, I used a JSON dataset from the USGS (United States Geological Survey) GeoJSON Feed to pull information on all earthquakes in the last month to create an earthquake visualization map in order to help the USGS to better educate the public and other government organizations (and hopefully secure more funding) on issues facing our planet. By using Leaflet, I was able to plot all the earthquakes based on their longitude and latitude. I added data markers that reflect the magnitude of the earthquake by their size and the depth of the earthquake by color, as well as popups that provide additional information about the earthquake when its associated marker is clicked. For Part 2, I added illustrations of the relationship between tectonic plates and seismic activity and additional base maps to choose from.
